# 출시 체크리스트 (1차 프로토타입, M5)

상태: 2026-10-17 점검. 법률 자문이 아니다 (brand-and-tone §1).

## 1. 법·윤리 체크리스트 점검 (brand-and-tone §5)

| 항목 | 결과 | 근거·방법 |
|---|---|---|
| 실제 브랜드·학교·인물·단체명이 화면·코드·에셋·커밋 메시지·SEO 메타에 없는가 | ✅ | `npm run check:content`가 `src content public index.html spike.html README.md dist`를 금지어 목록(`scripts/forbidden-words.txt`)으로 검사 — CI·빌드 게이트. 이 브랜치의 커밋 메시지도 같은 검사기로 0건 확인. 출처 기록(`docs/research`)은 범위 밖 |
| 로고·색·아이콘·레이아웃이 특정 실제 서비스를 연상시킬 만큼 유사하지 않은가 | ✅ (자체 판단) | 가상 팔레트 3종(`content/themes/*.json`), 좌석은 젤리빈 모양, 아이콘은 자체 제작 시계(글꼴 없음). 실제 화면 대조는 소유자가 `design/stages/*.md`로 진행 — **레이아웃을 실제와 맞출 때 트레이드 드레스 위험 재확인 필요** |
| 문구가 실제 공지를 복사하지 않았는가 | ✅ | 모든 문구 자체 작성(`content/copy/ko.json`). 짧은 관용 표현만 사용: "이미 선택된 좌석입니다", "수강신청 기간이 아닙니다!", "정원이 초과되었습니다" (realism-findings §5) |
| 입력 UI가 실제 개인정보·비밀번호를 요구하지 않는가 | ✅ | 입력칸은 보안문자·화면에 보이는 가상 생년월일·시드 코드뿐. 로그인은 버튼만(가상 학번 표시, "실제 정보를 입력하지 마세요" 안내). 결제 화면에 "실제 결제는 일어나지 않습니다" |
| 첫 화면 또는 푸터에 패러디 고지가 있는가 | ✅ | 홈 푸터, 플레이 화면 하단, `README.md`, 매니페스트 설명 |
| 매크로·우회·부정 구매를 가르치는 내용이 없는가 | ✅ | 매크로·직링·우회 관련 문구 없음. 함정 카드(새 탭, 친구 폰, 무통장 속설)는 "하면 손해"로 풍자 |
| 사건·피해자를 소재로 삼지 않았는가 | ✅ | 특정 사건·학교 장애를 이름으로 언급하지 않음. 증상(무한 로딩 등)만 일반화 |
| 에셋(폰트·소리·이미지) 라이선스를 문서에 기록했는가 | ✅ | `docs/assets-licenses.md` (시스템 글꼴, 합성 비프음, 자체 제작 아이콘) |
| 수익화를 하게 되면 재검토했는가 | ➖ 해당 없음 | 개인용, 광고·인앱 구매 없음 (game-rules §13) |

남은 사람 작업 (prototype-scope §7): 가상 브랜드명 상표·웹 검색(「딱표」「수강쇼핑」「이러닝쿨」「모찌밴드」「대충대학교」) — [미확인].

## 2. PWA·홈 화면 추가 확인 항목 (difficulty §4.3 ⑥)

자동 확인(e2e `pwa.spec.ts`, Chromium): 매니페스트·아이콘 경로가 `/1min/` 아래에 있음, 서비스 워커 설치 후 **오프라인에서 앱이 뜨고 판을 시작**함.

아이폰 사파리에서 소유자가 확인할 것:

1. [ ] 공유 버튼 → "홈 화면에 추가" → 아이콘(분홍 바탕 시계)과 이름 "1분 전"이 보인다
2. [ ] 홈 화면 아이콘으로 열면 주소창 없이 전체 화면(standalone)이다
3. [ ] 상단 상태 표시줄·노치와 HUD(남은 시간)가 겹치지 않는다 (safe-area)
4. [ ] 하단 고정 버튼(좌석선택완료·신청 완료)이 홈 인디케이터와 겹치지 않는다
5. [ ] 비행기 모드에서 홈 화면 아이콘으로 열어도 튜토리얼·티켓팅 한 판이 돈다
6. [ ] 새 버전 배포 뒤 앱을 두 번 열면 새 버전이 뜬다 (서비스 워커 갱신)
7. [ ] 홈 화면 앱과 사파리 탭의 기록(localStorage)이 따로 저장되는지 확인 [기억: iOS는 분리]
8. [ ] 7일 이상 안 열었을 때 기록이 지워지는지 (ITP 정책 [기억]) — 지워져도 앱은 정상
