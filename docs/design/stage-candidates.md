## 1. 후보 목록

각 스테이지는 **미션 체인**(순서대로 완료할 단계)과 **방해 카드 풀**(5개 이상)을 가진다. 방해 카드 ID는 `design/hazard-system.md`의 공통 카드와 별개로 스테이지 고유 카드다.

### A. 콘서트 티켓팅 — 가상 예매처 「딱표」 / 가상 밴드 「모찌밴드」
- 모드: 오픈형 · 미션 체인: 정각 클릭 → 대기열 → 보안문자 → 구역 → 좌석 → 결제
- 방해 카드
  1. **줄어드는 대기 숫자**: 새로고침 유혹 버튼이 흔들림. 누르면 대기 초기화 [확인 S6, S10]
  2. **보안문자 + 키보드**: 키보드가 올라와 확인 버튼을 가림 [확인 S4 / 터치는 추측]
  3. **좌석 가로채기**: 고른 좌석이 직전에 사라짐 (자체 문구 "앗, 한발 늦으셨어요") [사용자 제시, 문구 [미확인]]
  4. **광클 차단**: 구역 이동을 연타하면 쿨다운 [2차]
  5. **결제 타이머 압축** [2차 S5]
  6. **1계정 1대기열**: "친구 폰으로도 줄 서기" 선택지가 함정 [확인 S4]
  7. **팝업 차단됨** [2차 S5]
  8. **카톡 알림**: "엄마: 잡았어?" 오버레이 [확인 S8 맥락]
- 터치 포인트: 좌석도에서 작은 좌석 탭 오차, 구역 핀치 줌 충돌, 키보드 가림

## 3. 1차 출시 5개 추천

1. **A 티켓팅**: 대표 컷. 공유 문구와 밈 어휘가 가장 풍부하다.
2. **B 수강신청**: 같은 "오픈형 폼 UI" 구조라 엔진 일반성을 검증하기 좋다. 서버 지연·광클 제한 카드가 구체적으로 확인된 자료가 많다.
3. **C 과제 업로드**: 원작 계보와 연결되고 **마감형** 모드가 있어 엔진 다양성을 보장한다. 병렬 창이라는 다른 감각을 준다. 법적 위험이 가장 낮다.
4. **D 명절 기차표**: 연령대를 넓히는 소재. 대기번호 숫자와 부모님 전화가 강한 웃음 포인트이고 취소표 보너스 라운드의 자연스러운 자리다.
5. **E 한정빵 오픈런**: 폼 UI가 아닌 **공간형·스와이프 UI**라 라인업이 단조롭지 않다. 가상 빵이라 IP 위험을 피한다.

보류: F는 A와 메카닉이 겹치고 근거가 얇다. H는 A의 스킨으로 2차에. G·I·J는 조사 후 재평가.

권장 해금 순서(→ `design/difficulty-results-touch.md`): 튜토리얼(C의 쉬운 변형) → A → B → D → E. 이유: 첫 판은 모든 사람이 이해하는 "숙제 업로드"로 성공시키고, 이후 공감 강한 스테이지로 확장한다.
