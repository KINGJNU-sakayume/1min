# 에셋 라이선스

| 에셋 | 출처 | 라이선스 | 비고 |
|---|---|---|---|
| 글꼴 | 사용자 기기의 시스템 글꼴 (`system-ui`, Apple SD Gothic Neo, Malgun Gothic, Noto Sans KR) | 배포하지 않음 | 웹 글꼴 파일을 포함하지 않는다 |
| 앱 아이콘 `public/icons/*.svg`, `*.png` | 자체 제작 (도형만, 글꼴 없음). PNG는 `scripts/make-icons.ts`로 SVG에서 렌더링 | 이 저장소와 같음 | 11:59를 가리키는 시계 |
| 이미지 | 없음 (CSS 도형과 이모지만 사용) | — | 이모지는 사용자 기기 글꼴로 렌더링 |
| 소리 | Web Audio API로 실시간 합성한 비프음 (`src/ui/feedback.ts`) | 자체 생성 | 파일 없음 |

새 에셋을 추가하면 이 표에 출처·라이선스를 먼저 기록한다 (`design/brand-and-tone.md` §5).
