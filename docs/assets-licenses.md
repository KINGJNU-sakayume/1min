# 에셋 라이선스

| 에셋 | 출처 | 라이선스 | 비고 |
|---|---|---|---|
| 글꼴 | 사용자 기기의 시스템 글꼴 (`system-ui`, Apple SD Gothic Neo, Malgun Gothic, Noto Sans KR) | 배포하지 않음 | 웹 글꼴 파일을 포함하지 않는다 |
| 이미지·아이콘 | 없음 (CSS 도형과 이모지만 사용) | — | 이모지는 사용자 기기 글꼴로 렌더링 |
| 소리 | Web Audio API로 실시간 합성한 비프음 | 자체 생성 | 파일 없음 |

새 에셋을 추가하면 이 표에 출처·라이선스를 먼저 기록한다 (`design/brand-and-tone.md` §5).
